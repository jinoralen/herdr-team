# `--fyi` and `--re` instead of message types

Agents mark a message that needs no reply with `--fyi`, which wakes nobody and rides along with the
recipient's next delivery, and say which message they answer with `--re mN`. A taxonomy (question /
answer / done) was rejected: prose already says that, and agents would mislabel it. `--fyi` earns its
place by changing delivery, not just labelling: closing notes cost nobody a turn. Conversations end
by the guide's rules (ask explicitly, close with an FYI, don't post to agree), not by a hard cap.
